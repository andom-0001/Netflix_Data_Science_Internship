# Netflix Data Science Internship Project

## Overview

This project was completed as part of a Data Science internship at Auspify Technologies.

The project uses a Netflix titles dataset to perform data cleaning, exploratory data analysis, recommendation system analysis, and trend prediction.

## Tasks Completed

### Task 1 – Data Cleaning & Preprocessing
- Loaded the Netflix dataset using Pandas
- Checked missing values and duplicate records
- Cleaned inconsistent text values
- Converted date information
- Extracted duration value and duration unit
- Created a cleaned dataset

### Task 2 – Exploratory Data Analysis
- Analyzed dataset structure and statistics
- Compared Movies and TV Shows
- Analyzed release-year trends
- Identified top countries
- Analyzed popular content categories
- Examined ratings
- Created visualizations using Matplotlib and Seaborn

### Task 3 – Recommendation System Analysis
- Selected content-related features
- Combined textual features
- Applied text preprocessing
- Used TF-IDF vectorization
- Calculated cosine similarity
- Generated content-based recommendations

### Task 4 – Trend Prediction Analysis
- Analyzed yearly Netflix content trends
- Created historical trend visualizations
- Built a Linear Regression model
- Evaluated predictions using MAE, RMSE and R²
- Generated future trend projections

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
